# Support

- **Docs:** https://joe-broadhead.github.io/zephyr-flow/
- **Bugs:** GitHub Issues
- **Security:** GitHub Security Advisories (see [SECURITY.md](SECURITY.md))
- **Discussions:** GitHub Issues for now

When filing a bug, include:

- macOS version and chip (M1/M2/…)
- ZephyrFlow version (`v0.0.0`)
- Whether Accessibility / Microphone / Speech are granted
- Relevant lines from `~/Library/Logs/ZephyrFlow/zephyrflow.log` (no need to paste full history JSON)
