# Contributing

See the root [CONTRIBUTING.md](https://github.com/joe-broadhead/zephyr-flow/blob/master/CONTRIBUTING.md).

## Quick loop

```bash
swift run ZephyrFlowCoreTests
./Scripts/build_app.sh debug
open Dist/ZephyrFlow.app
```

## Ground rules

1. Privacy first — no analytics, no default network  
2. Actor + protocol architecture for STT / insert / flow  
3. Insertion changes need multi-app manual checks  
4. UI should stay premium (glass panel is a feature)
