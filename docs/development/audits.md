# Audits

Engineering audits (security, privacy, peer review) are **throwaway process artifacts**.

They are **not** stored in this repository. Agents and contributors should:

- Run audits in the conversation or a temp directory outside the repo
- Never commit `AUDIT.md`, `*_AUDIT.md`, or similar dumps under `docs/`

Stable product guidance lives in:

- [Privacy](../guide/privacy.md)
- [Security](../operations/security.md)
- Root [SECURITY.md](https://github.com/joe-broadhead/zephyr-flow/blob/master/SECURITY.md)
